# OQSHOM — Restoran sayti

Responsive, o‘zbek tilidagi restoran landing-page loyihasi. HTML, CSS va JavaScript yordamida tayyorlangan; alohida build jarayoni talab qilinmaydi.

## Ishga tushirish
1. ZIP faylni oching.
2. `index.html` faylini brauzerda oching.

## GitHub'ga joylash
1. GitHub'da yangi repository yarating (masalan, `oqshom-restoran`).
2. Ushbu papkadagi barcha fayllarni repository'ga yuklang.
3. `Settings → Collaborators` bo‘limidan 2–3 do‘stingizni taklif qiling.
4. Do‘stlaringiz `git clone` qilib, o‘z branch'larida ishlashi va Pull Request yuborishi mumkin.

## Netlify'ga deploy
1. Netlify hisobingizga kiring.
2. `Add new site → Import an existing project` ni tanlang.
3. GitHub repository'ni ulang.
4. Build command va Publish directory maydonlarini bo‘sh qoldiring (yoki Publish directory: `.`).
5. `Deploy site` tugmasini bosing.

## Muhim
- Telefon raqami, manzil, ish vaqti va menyu narxlari namuna sifatida kiritilgan — haqiqiy ma'lumotlaringizga almashtiring.
- Stol band qilish formasi hozircha demo: ma'lumotni serverga yubormaydi. Haqiqiy buyurtmalar uchun backend yoki Netlify Forms ulash kerak.
- Rasmlar Unsplash'dan internet orqali yuklanadi.
